📐 数据口径说明

  • 询盘 SLA：新询盘 4h 内联系、24h 内报价、48h 内跟进；SLA 基于最后活动时间（updated_at），非创建时间。
  • 转化率：成交数 ÷ 非归档询盘总数；渠道转化率 = 该渠道成交 ÷ 该渠道询盘。看板与询盘中心口径一致（已归档不计入）。
  • 待跟进：状态未终结（非成交/流失/归档）且下次跟进时间已到期或未设置。
  • SEO 评分（100 分）：Title 15 + Meta 15 + Tagline 10 + 主图 10 + FAQ 10 + 阶梯价 10 + 价格/MOQ 10 + 描述 10 + Slug 覆盖 10。
  • 图片规范：1:1 比例、最长边 ≤1600px、≤1.5MB、webp 优先；主图 + 附图 4-5 张；alt 为买家可读的英文描述。
  • 部署链路：保存修改 → GitHub 写入 → Actions 自动构建（约 2 分钟）→ Cloudflare Worker 上线。

🔧 常见问题排查

  • 看板 GitHub 数据无法读取：未鉴权 API 限 60 次/小时/IP（看板每次刷新消耗 2 次），稍后自动恢复；配置 OPS_GH_PAT 可提升额度。
  • 保存失败 server-not-configured：设置中心配置 GitHub PAT（OPS_GH_PAT）后重试。
  • 询盘读取失败：确认已登录；Supabase 需先执行 supabase-migration-inquiries-v2.sql 迁移。
  • 产品图 404 / 占位：图片经 Accio CDN → GitHub 两级代理；新上传图需等自动部署完成（约 2 分钟）。
  • AI 建议不可用：设置中心配置 LLM_API_KEY / LLM_ENDPOINT。
  • 驾驶舱无数据：需 GA4_SERVICE_JSON + GA4_PROPERTY_ID（GSC 可选）。
  • 自动部署失败：查看 GitHub Actions 运行日志；常见原因为 Secrets 缺失或构建错误。
